# Login Background Design

Replace the soft neon city illustration with a sharp abstract bitmap. The image uses crisp graphite architectural planes, a restrained data grid, and small cyan/coral accents. It contains no people, city, devices, text, logos, gradients, glowing blobs, or recognisable objects. The left half remains calm and dark so the login panel stays readable; detail is concentrated toward the right and survives desktop and mobile cover crops. The final project asset is a high-resolution WebP and keeps the existing login layout unchanged.
